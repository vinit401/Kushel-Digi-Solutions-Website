## 🚀 Getting Started

### Prerequisites
- Node.js `v18+`
- npm or yarn

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/your-username/kds-digital-agency.git

# 2. Navigate into the project
cd kds-digital-agency

# 3. Install dependencies
npm install

# 4. Start the development server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

### Build for Production

```bash
npm run build
```

## 🌙 Dark Mode

The site features a **full-page dark mode** toggle built into the navbar.

- Toggle persists across all sections
- Smooth CSS transitions on every element
- Logo auto-inverts to stay visible in dark mode
- Accessible toggle button with emoji indicator (☀️ / 🌙)
